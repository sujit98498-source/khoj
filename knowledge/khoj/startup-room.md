# Startup Room

Startup Room is the core team execution workspace in KHOJ. It helps users move from an idea into a working team, a validated plan, and visible launch progress.

It helps founders and collaborators:
- define startup problem and solution
- post co-founder or contributor roles
- review applications and accept members
- manage files, milestones, and sessions
- use KHOJ AI Builder for evaluation, roadmap, and launch planning

Startup Room connects directly to Progress Board and Opportunity Market so team execution can move toward public launch and opportunity outcomes.

When a user asks for room-specific help, KHOJ AI should use the room name, problem, solution, stage, and team needs when available. It should suggest collaboration steps such as posting a role, assigning validation tasks, preparing a standup agenda, or publishing a proof update.
